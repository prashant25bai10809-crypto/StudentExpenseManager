# Project Statement

## Title

Student Expense Manager

## Problem Statement

Students often have difficulty keeping track of their daily expenses. Small expenses such as food, transportation and stationery can accumulate over time.

The Student Expense Manager provides a simple way to record and manage these expenses.

## Objective

The objective of this project is to develop a Java-based application that allows students to:

1. Record expenses.
2. View recorded expenses.
3. Search expenses.
4. Delete expenses.
5. Calculate monthly expenses.
6. View category-wise spending.
7. Save and load expense records.

## Scope

The project is designed as a simple console-based application.

The application uses Java collections for temporary data storage and text-file based storage for permanent data.

No database is used.

## Target Users

The main target users are:

- College students
- University students
- Students who want to track their daily expenses
- Students who want a simple and easy-to-use expense management system

## High-Level Features

The main features of the system are:

- Add and record expenses
- View all expenses
- Search expenses by category or description
- Delete expenses using an ID
- Generate monthly expense summaries
- Display category-wise spending
- Save expenses to a text file
- Load previously saved expenses

## Functional Requirements

### Add Expense

The user can enter:

- Category
- Description
- Amount
- Date

### View Expenses

The application displays all stored expenses.

### Search Expense

The user can search using category or description.

### Delete Expense

The user can delete an expense using its unique ID.

### Monthly Summary

The application calculates the total expenses for a selected month and displays category-wise totals.

### File Storage

The application can save expenses to a text file and load them when required.

## Non-Functional Requirements

- Simple user interface
- Easy to use
- Basic input validation
- Maintainable Java code
- No external database dependency

## Conclusion

The Student Expense Manager demonstrates the practical use of Java programming concepts such as OOP, collections, interfaces, exception handling and file handling.
